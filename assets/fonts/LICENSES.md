# Licenze dei font

I font locali in questa cartella sono distribuiti con licenza [SIL Open Font License 1.1](https://openfontlicense.org/):

- Outfit — Rodrigo Fuenzalida / Google Fonts
- Nunito Sans — Vernon Adams, Jacques Le Bailly / Google Fonts
- Merriweather — Eben Sorkin / Google Fonts

I file `.woff2` derivano dai font variabili del repository pubblico ufficiale di Google Fonts, ridotti al solo alfabeto latino (con punteggiatura e frecce usate nel sito) e, per Nunito Sans, ai pesi 400–700. Sono ospitati localmente per evitare il caricamento remoto dei font dal browser del visitatore. Gli originali `.ttf` sono conservati in `private/originals/fonts/` (cartella locale ignorata da Git).
